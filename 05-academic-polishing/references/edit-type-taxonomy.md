# 润色修改类型受控词表与守恒清单

## 修改类型（受控）

| 类型 | 说明 |
|---|---|
| `grammar` | 主谓一致、时态语态、冠词介词、单复数、悬垂修饰等 |
| `punctuation` | 标点、连字符、破折号 |
| `diction` | 用词准确性、搭配 |
| `tone` | 学术语气/语域贴合 |
| `term` | 术语统一、缩写首次给全称 |
| `coherence` | 连接词、指代清晰（不改变语义） |
| `semantics` | 仅在原意确实表达不清时的小幅澄清（须特别谨慎） |

## 语义守恒清单（逐句核对，不得改变）

- 限定强度：`may/suggest/indicate/significantly/only/all/unless/to the extent` 等逐项保留。
- 数据与单位：数值、单位、范围、精度原样保留。
- 引用编号与图表指向：`[3]`、`Fig. 2`、`Table 1` 原样保留。
- 否定与逻辑关系：否定、因果、让步、转折不反转不弱化。
- 术语译法：符合领域惯例，全篇一致。

## 修改记录格式

`{ id, locator, original, revised, type, reason }`

- 未改动处不制造修改；改动最少化为原则。
- 不确定是否该改处：保留原文并列入 `uncertainty`，不擅自改。
