# 学术语言润色：逐句修改、限定守恒、改动可复核

把一段/一篇学术文本润色到"语法正确、语气贴合、语义不变"，并对每一处修改给出原文—改文—类型—理由，而非整段重写或只给建议。

## 运行契约

- 输入：`/input/task.md`、`/input/case.json`、`resources.yaml` 及事实底稿/稿件/术语表/风格指南。
- 工作目录 `/app/work`；最终结果写入 `/app/output/`。
- 先读真实底稿；超长输入、编码混乱、公式与引用混杂、中英日混排、术语表冲突、目标文体不明等如实记录。
- `/app/output/result.json` 必须包含：`case_id`、`status`、`output_contract` 全部字段、`sources`、`uncertainty`、`change_records`。
- 预算 64 次模型请求 / 900 秒：逐句/逐段处理，不一次重写全文；先存已改部分。
- 交付"润色后完整文本 + 逐句修改说明"；可编辑产物附真实渲染预览（PDF/PNG）。

## 工作流

1. **识别边界**：读 `task.md`/`case.json`，确认受众、文体（期刊论文/基金申请/学位论文等）、格式约束、术语表与风格规则、处理区间。
2. **读底稿**：先完整读原文，识别主张强度、限定词、数据/单位、引用编号、图表指向、术语。
3. **逐句最小编辑**：只改该改的（语法、句法、搭配、标点、语气、术语统一）；保留原意与结构，不做不必要的改写。
4. **限定守恒**：润色不得加强或削弱结论强度；`may/suggest/indicate`、`significantly`、`only/all`、数值与单位、引用编号、图表指向逐项保留。
5. **术语与风格**：按术语表统一术语；缩写与符号首次出现给全称并保持一致；贴合目标文体语域。
6. **生成修改记录**：每处给出 `原文 | 改文 | 修改类型 | 理由`；修改类型用 `references/edit-type-taxonomy.md` 的受控词表，语义守恒逐项对照该文件清单；未改动处不强行制造修改。
7. **输出**：润色后全文 + 修改清单 + 术语表 + 不确定项，写入 `result.json`，并运行 `python3 scripts/check_semantics.py result.json` 校验语义守恒。

## 四条硬规则

### 改得对
- 真正改掉语法、句法、搭配、标点、用词错误，而非换一种说法掩盖。

### 说得像
- 符合目标文体与语域，术语全篇统一，读起来仍是同行写的学术文本。

### 没改坏
- 原意、限定强度、数据、单位、引用编号、图表指向保持原样；不在润色中偷偷加强或削弱结论。

### 讲得清
- 每一处修改有原文、改文、类型与理由，第三方据此判断"该不该改"。

## 输出结构

`/app/output/result.json`（合并 task.md 的 `output_contract`）：

```json
{
  "case_id": "...",
  "status": "success|partial|unable",
  "polished_text": "...",
  "edits": [
    {"id": "E1", "locator": "¶2 第3句", "original": "...", "revised": "...", "type": "grammar|term|tone|punctuation|semantics", "reason": "..."}
  ],
  "term_table": [{"term": "...", "note": "首次出现已给全称"}],
  "sources": [...],
  "uncertainty": [{"locator": "...", "issue": "目标文体不明", "action": "按通用学术文体处理并标注"}],
  "change_records": [...]
}
```

## 异常处理

- 超长输入：按段处理，保存已改部分，不一次请求重写全文。
- 编码混乱/中英日混排：保留可读部分，标出无法可靠处理的片段。
- 公式与引用混杂：公式、引用编号、图表指向原样保留，不重排不改写。
- 术语表内部冲突：按"首次出现→领域惯例"定优先级并记录决定。
- 目标文体不明：按通用学术文体处理并显式标注假设。

## 自查清单

1. 是否逐句最小编辑，而非整段重写？
2. 限定强度、数据、单位、引用编号、图表指向是否原样保留？
3. 术语是否全篇统一、缩写首次出现是否给全称？
4. 每处修改是否有原文/改文/类型/理由？
5. 是否明确标注了不确定项与未改动范围？
6. `result.json` 是否字段齐全、状态诚实？
