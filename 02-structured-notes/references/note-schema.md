# 结构化笔记字段与锚点约定（文献总结）

## 论文卡片字段（统一字段，便于比较与检索）

| 字段 | 含义 | 必填 |
|---|---|---|
| `research_question` | 研究问题/目标 | 是 |
| `data` | 数据/材料/对象 | 是 |
| `methods` | 方法（含关键条件） | 是 |
| `findings` | 主要发现（含数值） | 是 |
| `conclusion` | 作者结论 | 是 |
| `limitations` | 作者自述局限 | 是 |
| `premises` | 让结论成立的前提条件 | 是 |

## 章节笔记字段

| 字段 | 含义 |
|---|---|
| `section` | 章节名（与论文一致） |
| `pages` | 页码范围 |
| `purpose` | 本章目的 |
| `content` | 方法/结果/论点要点 |
| `link_prev` / `link_next` | 与上下章承接关系 |

## 知识点与锚点格式

知识点：`{ id, statement, anchor, quote }`

锚点格式（可复核的最小定位）：
- 文本：`p4 ¶2`（页码 + 段落）
- 图表：`Fig. 2` / `Table 1`
- 公式：`Eq. (5)`

锚点规则：禁止"见全文"；每条关键笔记必须有具体锚点 + 短引文（≤40 字）。
