# bohrium-skill-ai-literature
玻尔产品周赛·地大站赛｜AI文献阅读与学术写作 10赛题Skill集合

## 赛题清单
1. 文献文档解析
2. 文献翻译
3. 文献总结与结构化笔记
4. Nanopublication
5. 文献知识图谱构建
6. 学术语言润色
7. 参考文献与引用管理
8. 引言与相关工作写作
9. 方法与实验章节写作
10. LaTeX写作与编译

## 目录说明
每个 `skill_xx_xxx` 文件夹为一个独立参赛Skill，内含：
- SKILL.md：Skill定义文件（Bohrium规范）
- main.py：运行脚本
- README.md：该赛题方案说明、边界、测试示例
