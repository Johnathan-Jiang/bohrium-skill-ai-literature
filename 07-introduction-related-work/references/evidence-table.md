# 引言证据表模板（论断—引用—来源）

写作前先建证据表：每句要写进正文的断言先登记出处，再动笔。

## 模板（TSV / JSON）

| claim | citation | source | note |
|---|---|---|---|
| 现有方法在长序列上退化 | [3] | Smith 2024, DOI | 原文：第 4 节报告退化 |

JSON：

```json
{
  "claim": "...",
  "citation": "[3]",
  "source": "Smith 2024, DOI",
  "quote": "...（原文要点）",
  "locator": "p4 §4"
}
```

## 分组与空白推导

- 相关工作按**问题/方法/技术路线**分组，每组给"共同点 + 差异 + 局限"。
- 研究空白只能由**已引文献的缺口**推出；无对应引用时显式标"作者判断"。
- 贡献表述逐条对应本文方法/图表/实验（`contribution_mapping`）。

## 引用核验清单

1. 引用真实存在？元数据（作者/年份/来源）准确？
2. 转述与原文一致，未加强/削弱其结论？
3. 每条引用是否落到具体论断句？
