# 引言与相关工作写作：论断—引用绑定、空白可推导、贡献可对照

交付可直接进入论文的引言与相关工作：研究背景、相关工作、研究空白、贡献四部分齐全且彼此承接，每条论断落在具体引用上，空白由已引文献缺口推出。

## 运行契约

- 输入：`/input/task.md`、`/input/case.json`、`resources.yaml` 及事实底稿、相关工作文献、本文方法/结果材料。
- 工作目录 `/app/work`；最终结果写入 `/app/output/`。
- 先读真实材料；材料不足、文献库为空、引用查不到原文、目标期刊格式未知、空白缺乏依据等如实记录。
- `/app/output/result.json` 必须包含：`case_id`、`status`、`output_contract` 全部字段、`sources`、`uncertainty`、`change_records`。
- 预算 64 次模型请求 / 900 秒：先建"论断—引用—来源"证据表，再按四部分写作，后核验。
- 可编辑产物（docx/tex/md）附真实渲染预览（PDF/PNG）。

## 工作流

1. **识别边界**：读 `task.md`/`case.json`，确认学科、目标期刊/格式、引用格式、材料范围、篇幅。
2. **建证据表**：从材料抽「论断/事实 → 支撑来源（作者/年份/DOI）→ 原文要点」，用 `references/evidence-table.md`。每句要写进正文的断言先在此登记出处。
3. **写研究背景**：从领域脉络、具体问题、技术约束入手，指出为什么这个问题现在重要；不写"近年来受到广泛关注"式空转铺垫。
4. **写相关工作**：按问题/方法/技术路线**分组比较**，准确转述各工作的结论、适用条件与局限；不逐篇摘要拼接。
5. **写研究空白**：由**已引文献的缺口**推出（"现有工作未解决 X"必须有对应引用支撑或明确标注为作者判断），并说明本文如何填补。
6. **写贡献**：贡献表述与本文实际方法、图表、实验结果一一对应；不夸大。
7. **核验**：逐条核对引用存在、元数据准确、论断与来源匹配；空白推导与贡献对照可独立复核。
8. **输出**：引言+相关工作成稿 + 证据表 + 空白推导 + 贡献对照，写入 `result.json`，并运行 `python3 scripts/check_evidence.py result.json` 校验引用覆盖与空白依据。

## 四条硬规则

### 立得住
- 背景指向真实研究脉络与具体未解决问题，而非空转铺垫。

### 分得清
- 相关工作按问题/方法/路线分组比较，准确转述结论、适用条件与局限。

### 说得实
- 空白由已引文献缺口推出并说明本文如何填补；断言有出处或明确标注为作者判断。

### 对得上
- 贡献与本文实际方法/图表/结果对应；引用覆盖与元数据经得起逐条核对。

## 输出结构

`/app/output/result.json`（合并 task.md 的 `output_contract`）：

```json
{
  "case_id": "...",
  "status": "success|partial|unable",
  "introduction_text": "...",
  "evidence_table": [{"claim": "...", "citation": "[3]", "source": "Author Year, DOI", "note": "..."}],
  "gap_derivation": [{"gap": "...", "from_citations": ["[2]","[5]"], "basis": "文献缺口|作者判断"}],
  "contribution_mapping": [{"contribution": "...", "supported_by": "Fig.2 / 实验3"}],
  "sources": [...],
  "uncertainty": [{"claim": "...", "issue": "引用查不到原文", "action": "标注待核"}],
  "change_records": [...]
}
```

## 异常处理

- 材料不足/文献库为空：只写有证据支撑的部分，其余标"材料不足"并列出待补清单。
- 引用查不到原文：不转述其具体结论，改用可核实的表述或标注待核。
- 空白缺乏依据：显式标为"作者判断"，不伪装成文献推导。
- 目标期刊格式未知：按通用学术格式处理并显式标注假设。
- 贡献与实际结果不符：调整贡献表述到与证据一致，不夸大。

## 自查清单

1. 四部分（背景/相关工作/空白/贡献）是否齐全且彼此承接？
2. 他人工作转述是否与原文一致、引用元数据是否真实？
3. 空白是否由已引文献缺口推出，本文如何填补是否说明？
4. 贡献是否与本文实际方法/图表/结果一一对应？
5. 每条引用能否回到来源，空白推导与贡献对照能否复核？
6. `result.json` 是否字段齐全、状态诚实？
